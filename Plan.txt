Project Brief: EdTech Unified Reader ExtensionGoal: Build a browser extension that aggregates course discussion posts from Piazza, Ed Discussion, and Campuswire into a single unified client-side UI. The extension will bypass CORS and utilize the user's active session cookies by executing network requests via a background Service Worker.Tech Stack:Framework: Plasmo (React + TypeScript)Styling: Tailwind CSSTarget Manifest: Manifest V3 (MV3)1.Initialize the Plasmo Project:Generate the base scaffolding for the extension.Agent Instructions:Run pnpm create plasmo edtech-reader (or npm/yarn equivalent).cd edtech-readerInstall Tailwind CSS and its dependencies following Plasmo's official Tailwind integration guide.Verify the directory structure (create popup.tsx, background.ts, and a src/ directory if preferred).2.Configure Manifest Permissions:The extension needs permissions to bypass CORS and read data from the target platforms. Plasmo handles the manifest inside package.json.Agent Instructions:Open package.json.Add a "manifest" object containing "permissions" and "host_permissions".Request "permissions": ["storage", "cookies"].Request "host_permissions": ["*://*[.piazza.com/](https://.piazza.com/)*", "*://edstem.org/*", "*://*[.campuswire.com/](https://.campuswire.com/)*"]. This gives the background script the authority to make authenticated requests to these domains.3.Define the Unified Data Schema:Create the TypeScript interfaces that will normalize the data coming from three fundamentally different platforms.Agent Instructions:Create src/types/schema.ts.Define a UnifiedPost interface containing:id: stringplatform: 'Piazza' | 'Ed' | 'Campuswire'courseId: stringtitle: stringbodyHtml: stringauthorName: stringcreatedAt: stringurl: string (Deep link to the original post)Export this interface to be used by both the background workers and the React UI.4.Build Background Ingestion Scripts:This is the core engine. The background script will intercept the user's active session and fetch the raw data.Agent Instructions:Create background.ts (Plasmo will automatically bundle this as a Service Worker).Write three separate async fetch functions: fetchPiazzaPosts(), fetchEdPosts(), and fetchCampuswirePosts().For each function, use the standard fetch() API to hit the platform's internal endpoints. Note: Since host_permissions are set, the browser will automatically attach the user's active session cookies to these requests.Write normalization logic inside each function to map the raw JSON responses into the UnifiedPost array.5.Setup Plasmo Messaging API:The UI cannot fetch data directly due to CORS. The UI must ask the background script to fetch the data on its behalf.Agent Instructions:Implement Plasmo's Messaging API.Create an endpoint in src/background/messages/getPosts.ts.In this message handler, call Promise.all([fetchPiazzaPosts(), fetchEdPosts(), ...]), merge and sort the arrays by date, and return the UnifiedPost[] array to the sender.6.Construct the React UI:Build the user interface that will display the aggregated posts.Agent Instructions:Open popup.tsx (or build a side-panel if preferred).Set up a React useEffect hook to send a message to the background script (chrome.runtime.sendMessage or Plasmo's @plasmohq/messaging) on mount to request the posts.Store the returned UnifiedPost[] array in React state.Render a list of cards using Tailwind CSS. Each card should display the platform badge, title, author, and a snippet of the body. Clicking the card should open the url in a new tab.Add basic filtering state (e.g., toggles to show/hide specific platforms or courses).
